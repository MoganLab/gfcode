# (liii pi ai providers qwen-token-plan-cn) 模块函数索引

`(liii pi ai providers qwen-token-plan-cn)` 提供阿里云百炼 QwenCloud Token Plan 团队订阅（中国区）服务商的内置配置定义、模型元数据及额度耗尽错误识别。

使用时导入：

```scheme
(import (liii pi ai providers qwen-token-plan-cn))
```

## 查看函数文档

使用以下命令查看函数文档和测试用例：

```bash
gf doc PI_QWEN_TOKEN_PLAN_CN_QUOTA_ERROR
```

## 函数分类索引

### 服务商配置与模型定义
- `PI_QWEN_TOKEN_PLAN_CN_PROVIDER` - Qwen Token Plan 团队订阅中国区服务商基础配置
- `PI_QWEN_TOKEN_PLAN_CN_BUILTIN_MODELS` - 内置模型定义列表

### 额度错误识别
- `PI_QWEN_TOKEN_PLAN_CN_QUOTA_ERROR` - 识别额度耗尽错误（初版占位，返回 #f）
