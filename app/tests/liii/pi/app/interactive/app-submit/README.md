# (liii pi app interactive app-submit) 模块函数索引

`(liii pi app interactive app-submit)` 提供应用层输入提交流程处理。

使用时导入：

```scheme
(import (liii pi app interactive app-submit))
```

## 查看函数文档

使用以下命令查看函数文档和测试用例：

```bash
gf doc pi-app-submit!
gf doc pi-parse-extension-command
```

## 函数分类索引

- `pi-app-submit!` - 提交普通消息或分发交互命令
- `pi-parse-extension-command` - 解析规范 slash command 名及原始参数（ST3 实现）
