# (liii pi app interactive app-selection) 模块函数索引

`(liii pi app interactive app-selection)` 提供独立于 jobs-chan 的“最新请求选择”通道发布辅助（latest-wins）。

使用时导入：

```scheme
(import (liii pi app interactive app-selection))
```

## 函数分类索引

- `pi-app-publish-request-selection!` - 发布一次完整请求选择快照到 request-selection-chan

详见当前目录下的单元测试用例。
