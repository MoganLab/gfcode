# (liii pi code modes verbose state) 模块函数分类索引

`(liii pi code modes verbose state)` 提供 verbose 模式 turn-box 可变状态的惰性初始化与思考状态槽访问。

使用时导入：

```scheme
(import (liii pi code modes verbose state))
```

## 查看函数文档

```bash
gf doc ensure-message-slots
```

- `ensure-message-slots` - 惰性补齐 turn-box 的消息缓冲、首行标记与思考状态盒槽位
