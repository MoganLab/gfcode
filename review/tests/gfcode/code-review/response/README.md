# (gfcode code-review response) 模块函数分类索引

`(gfcode code-review response)` 提供会话结束后的响应处理逻辑：将 Agent 最终消息归一化并转换为统一的审查成功报告或可读错误。

使用时导入：

```scheme
(import (gfcode code-review response))
```

## 查看函数文档

使用以下命令查看函数文档和测试用例：

```bash
gf doc pi-code-review-response
```
